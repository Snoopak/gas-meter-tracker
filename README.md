# 📷 Система обробки фотографій лічильників

Автоматична система для розпізнавання даних з фотографій лічильників та збереження в Excel.

## 🎯 Можливості

- ✅ Автоматичне розпізнавання тексту з фото (OCR)
- ✅ Витягування ключових даних: марка, серійний номер, рік випуску, показання
- ✅ Збереження в структуровану Excel таблицю
- ✅ Веб-інтерфейс для зручної роботи
- ✅ Пакетна обробка декількох фото
- ✅ Можливість ручного коригування даних

## 📋 Системні вимоги

### Ubuntu/Debian:
```bash
sudo apt-get update
sudo apt-get install -y tesseract-ocr tesseract-ocr-ukr tesseract-ocr-eng
sudo apt-get install -y python3 python3-pip
sudo apt-get install -y libgl1-mesa-glx libglib2.0-0
```

### Windows:
1. Встановіть Python 3.8+ з https://www.python.org/downloads/
2. Завантажте Tesseract OCR: https://github.com/UB-Mannheim/tesseract/wiki
3. Встановіть Tesseract та додайте його до PATH

### macOS:
```bash
brew install tesseract tesseract-lang
brew install python3
```

## 🚀 Встановлення

### 1. Клонуйте або завантажте файли проекту

### 2. Встановіть Python бібліотеки:
```bash
pip install -r requirements.txt
```

Або встановіть вручну:
```bash
pip install opencv-python pytesseract openpyxl Pillow Flask Werkzeug numpy
```

### 3. Перевірте встановлення Tesseract:
```bash
tesseract --version
```

Якщо команда не працює, знайдіть шлях до tesseract і встановіть його в коді:
```python
# У файлі meter_processor.py додайте:
import pytesseract
pytesseract.pytesseract.tesseract_cmd = r'C:\Program Files\Tesseract-OCR\tesseract.exe'  # Windows
# або
pytesseract.pytesseract.tesseract_cmd = r'/usr/bin/tesseract'  # Linux/Mac
```

## 💻 Використання

### Варіант 1: Веб-інтерфейс (найзручніше)

1. Запустіть веб-сервер:
```bash
python web_app.py
```

2. Відкрийте браузер та перейдіть за адресою:
```
http://localhost:5000
```

3. Завантажте фото лічильника (перетягніть або виберіть файл)

4. Перевірте та скоригуйте розпізнані дані

5. Натисніть "Зберегти в Excel"

6. Завантажте готовий Excel файл кнопкою "Завантажити Excel"

### Варіант 2: Командний рядок

#### Обробка одного фото:
```bash
python meter_processor.py
```
Програма запитає шлях до фото.

#### Пакетна обробка папки з фото:
```bash
python batch_processor.py
```
Оберіть режим 2 та вкажіть шлях до папки.

### Варіант 3: Використання як бібліотеки

```python
from meter_processor import MeterProcessor

# Створити процесор
processor = MeterProcessor('my_meters.xlsx')

# Обробити одне фото
data = processor.process_image('photo.jpg')

# Обробити з ручним коригуванням
data = processor.process_image('photo.jpg', manual_data={
    'brand': 'Zenner',
    'serial_number': 'ABC123456'
})
```

## 📊 Структура Excel файлу

Система створює Excel файл з такими колонками:

| № | Дата | Марка | Серійний номер | Рік випуску | Показання | Фото |
|---|------|-------|----------------|-------------|-----------|------|
| 1 | 30.10.2025 | Zenner | ABC123456 | 2020 | 12345.67 | meter1.jpg |

- **№** - порядковий номер запису
- **Дата** - дата обробки фото
- **Марка** - виробник/модель лічильника
- **Серійний номер** - унікальний номер
- **Рік випуску** - рік виготовлення
- **Показання** - поточні показання
- **Фото** - назва файлу фото

## 🎨 Особливості розпізнавання

Система може розпізнавати:

### Марка лічильника:
- Назви виробників (Zenner, Sensus, Itron, і т.д.)
- Моделі лічильників

### Серійний номер:
- Формати: ABC123456, 12345678, A1B2C3D4
- З маркуванням: "№", "Serial No", "Серійний №"
- Без маркування (розпізнавання по шаблону)

### Рік випуску:
- 4-значний формат: 2020, 2021, і т.д.
- З маркуванням: "Рік випуску", "Year"
- Валідація діапазону: 1990-2025

### Показання:
- Цілі числа: 12345
- Дробові числа: 12345.67
- З одиницями: 12345 кВт, 123.45 м³

## 📝 Поради для кращого розпізнавання

1. **Якість фото:**
   - Використовуйте добре освітлене фото
   - Уникайте бліків та тіней
   - Тримайте камеру паралельно до лічильника

2. **Кадрування:**
   - Розмістіть лічильник в центрі кадру
   - Захопіть всю інформаційну панель
   - Уникайте сторонніх об'єктів

3. **Фокус:**
   - Переконайтеся, що текст чіткий
   - Зробіть декілька фото, якщо потрібно

4. **Роздільність:**
   - Мінімум 1280x720 пікселів
   - Краще 1920x1080 або вище

## 🔧 Налаштування

### Зміна мови розпізнавання:
У файлі `meter_processor.py` змініть рядок:
```python
custom_config = r'--oem 3 --psm 6 -l ukr+eng'
```
На інші мови: `rus`, `pol`, `deu`, і т.д.

### Додаткова обробка зображення:
Можна налаштувати параметри в методі `preprocess_image()`:
- Зміна контрасту
- Рівень бінаризації
- Зменшення шуму

### Шаблони розпізнавання:
Додайте або змініть регулярні вирази в методі `parse_meter_data()`.

## ❓ Вирішення проблем

### Помилка: "Tesseract not found"
- Встановіть Tesseract OCR
- Додайте шлях до tesseract.exe в PATH (Windows)
- Або вкажіть шлях в коді (див. розділ Встановлення)

### Погане розпізнавання тексту
- Перевірте якість фото
- Спробуйте інше освітлення
- Використайте ручне коригування даних

### Excel файл не відкривається
- Закрийте файл, якщо він відкритий
- Перевірте права доступу до папки
- Видаліть файл та створіть новий

### Веб-інтерфейс не запускається
```bash
# Перевірте, чи порт 5000 вільний:
netstat -an | grep 5000

# Або запустіть на іншому порту:
# У файлі web_app.py змініть:
app.run(debug=True, host='0.0.0.0', port=8080)
```

## 🆘 Підтримка

Якщо виникли проблеми:
1. Перевірте, чи встановлено всі залежності
2. Переконайтесь, що Tesseract працює: `tesseract --version`
3. Спробуйте обробити тестове фото з чітким текстом
4. Перевірте формат та якість фото
